# Network Lab Screenshots

## Overview

This folder contains screenshots documenting my hands-on networking labs created with Cisco Packet Tracer.

These images provide visual evidence of network topologies, device configurations, connectivity tests, and troubleshooting activities.

## Screenshot Categories

### 1. Network Topology
Screenshots showing the network design, including routers, switches, end devices, and network connections.

### 2. IPv4 and IPv6 Configuration
Screenshots showing IP addressing, subnet masks, default gateways, and IPv6 configuration.

### 3. Router and Switch Configuration
Screenshots of Cisco IOS commands used to configure network devices.

### 4. Connectivity Testing
Screenshots demonstrating successful communication between devices using:
- Ping
- Traceroute
- Show IP Route
- Show IPv6 Interface Brief

### 5. Network Troubleshooting
Screenshots showing network problems, diagnostic commands, and the solutions implemented.

## Project Goals

- Demonstrate practical networking skills.
- Document network configuration and testing.
- Provide visual evidence of successful lab activities.
- Track my progress while learning Cisco networking technologies.


## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- GitHub

To build a professional networking portfolio that demonstrates my practical skills in network design, configuration, verification, and troubleshooting.
