# Cisco IOS Device Configurations

## Overview

This folder contains the Cisco IOS configurations used in my Packet Tracer networking labs.

The purpose is to document how routers and switches are configured to establish network connectivity, implement IP addressing, and apply basic security settings.

## Configuration Topics

- Basic router and switch configuration
- Hostname configuration
- IPv4 and IPv6 interface addressing
- Static routing
- Default gateway configuration
- SSH remote management
- Console and VTY line configuration
- Basic network security
- Network troubleshooting

## Network Devices

The first network project will include:

- Router R1
- Router R2
- Router R3
- Router R4
- Switch S1
- Switch S2
- Switch S3
- Switch S4

## Configuration Files

Each network device will have its own configuration file documenting the Cisco IOS commands used during the lab.

## Verification Commands

The following commands will be used to verify network configurations:

- `show running-config`
- `show ip interface brief`
- `show ipv6 interface brief`
- `show ip route`
- `show ipv6 route`
- `ping`
- `traceroute`

## Learning Objective

To develop practical skills in Cisco IOS configuration, network administration, routing, switching, and troubleshooting as part of my CCNA learning journey.

## Security Note

All configurations are created for educational purposes. Passwords, private cryptographic keys, and sensitive information will not be published.
