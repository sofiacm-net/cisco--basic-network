# Cisco Packet Tracer Labs

## Overview

This folder contains my hands-on networking projects created using Cisco Packet Tracer as part of my CCNA learning journey.

## Project Objectives

- Design and build network topologies.
- Configure Cisco routers and switches.
- Implement IPv4 and IPv6 addressing.
- Configure static routing and network connectivity.
- Practice basic network security and SSH access.
- Troubleshoot network connectivity issues.

## First Project: Four-Router Network

My first project will consist of:

- 4 Cisco Routers
- 4 Cisco Switches
- 4 PCs
- 4 Local Area Networks (LANs)

The goal is to establish communication between all four networks and verify connectivity using Cisco IOS commands.
